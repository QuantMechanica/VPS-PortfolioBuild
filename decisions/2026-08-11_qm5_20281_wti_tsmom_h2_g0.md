## Locked Rule

Evaluate only on the first processed `XTIUSD.DWX` D1 bar of a genuine broker-
month transition whose new month is odd (`1,3,5,7,9,11`). Reconstruct exactly
thirteen consecutive completed broker-month-end closes `C[0]..C[12]`, oldest
to newest. The newest endpoint must belong to the month immediately before the
decision month. Define the fixed twelve-month log return:

```text
twelve_month_return = ln(C[12] / C[0])

signal = BUY  when twelve_month_return > 0
         SELL when twelve_month_return < 0
         FLAT when twelve_month_return == 0 or state is invalid
```

Require positive finite closes, consecutive completed months, strictly
increasing endpoint timestamps, a finite logarithm, and no endpoint from the
current broker month. The eleven interior endpoints are mandatory continuity
evidence; there is no fallback to 252 D1 bars, a moving average, regression,
rank statistic, calendar direction, or prior pipeline result. Signal
magnitude never scales risk.

Consume and persist the odd decision month before history, signal, spread,
quote, ATR, sizing, news, or order gates. Close the prior package at the next
eligible odd-month transition before considering replacement, including when
the sign is unchanged. Do nothing at even-month transitions. Each entry uses
one `RISK_FIXED=1000` budget and a frozen `3.5 * ATR(20,D1)` hard stop. The
entry spread ceiling is 1,500 points. No take-profit is authorized. Close
after seventy calendar days if the normal bimonthly rollover close is missed.
Friday close and both news axes are disabled for the native-price package.
