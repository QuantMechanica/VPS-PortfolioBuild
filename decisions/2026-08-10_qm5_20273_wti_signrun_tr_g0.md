transition, reconstruct exactly thirteen consecutive completed broker-month-
end closes `C[0]..C[12]`, oldest to newest. The newest endpoint must belong to
the month immediately before the decision month. Define twelve chronological
log returns:

```text
r[i] = ln(C[i+1] / C[i]), i = 0..11
```

Scan oldest to newest. A strictly positive return extends the current positive
run and terminates the current negative run. A strictly negative return extends
the current negative run and terminates the current positive run. An exact-zero
return terminates both runs and belongs to neither direction. Retain the
longest positive run `L+` and longest negative run `L-` over the full twelve-
return window:

- `L+ >= 4` and `L+ > L-`: BUY WTI;
- `L- >= 4` and `L- > L+`: SELL WTI;
