## Locked Rule

On the first processed `XTIUSD.DWX` D1 bar of a genuine broker-month
transition, reconstruct exactly thirteen consecutive completed broker-month-
end closes `C[0]..C[12]`, oldest to newest. The newest endpoint must belong to
the month immediately before the decision month. Define twelve chronological,
non-overlapping monthly log returns and fixed exponential-recency weights:

```text
r[i] = ln(C[i+1] / C[i]),                         i = 0..11
age[i] = 11 - i                                   # newest return has age 0
half_life = 3.0 completed months
w[i] = 2 ^ (-age[i] / half_life)
weight_total = sum(w[i]),                         i = 0..11
exp_weighted_mean = sum(w[i] * r[i]) / weight_total

signal = BUY  when exp_weighted_mean > 0
         SELL when exp_weighted_mean < 0
         FLAT when exp_weighted_mean == 0 or state is invalid
```

Chronology is load-bearing: the newest return has weight one, a return three
months older has half that weight, and every return remains in the statistic.
There is no sort, clipping, fitted decay, adaptive half-life, single endpoint
return, horizon vote, calendar direction, external series, or fallback. The
signal magnitude never scales risk.

Consume and persist the decision month before history, spread, quote, ATR,
sizing, news, or order gates. Close the prior package at the next genuine
month transition before considering replacement, including when the sign is
unchanged. Each entry uses one `RISK_FIXED=1000` budget and a frozen
`3.5 * ATR(20,D1)` hard stop. No take-profit is authorized. Close after forty
calendar days if the normal rollover close is missed. Friday close and both
news axes are disabled for the full-month native-price package.
