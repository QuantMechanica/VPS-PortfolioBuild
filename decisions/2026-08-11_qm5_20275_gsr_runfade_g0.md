for `XAUUSD.DWX` and `XAGUSD.DWX`. For completed shift `k`, newest at `k=1`,
define the log ratio and chronological relative return:

```text
r[k] = ln(XAU_close[k]) - ln(XAG_close[k]),  k = 1..7
d[k] = r[k] - r[k+1],                       k = 1..6
```

Require exact timestamp alignment, positive finite closes, finite ratios and
returns, and consecutive D1 observations. A fresh upper run is
`d[1]..d[5] > 0` with `d[6] <= 0`; a fresh lower run is `d[1]..d[5] < 0` with
`d[6] >= 0`. Zero breaks a run. An upper run opens SELL XAU / BUY XAG; a lower
run opens BUY XAU / SELL XAG. The signal magnitude does not scale risk.

spread ceiling and 3,000-point XAG ceiling, no take-profit, and all-or-none
basket repair. Close an upper-run package on the first completed
nonpositive relative return; close a lower-run package on the first completed
nonnegative relative return. Close any package after twelve calendar days.
