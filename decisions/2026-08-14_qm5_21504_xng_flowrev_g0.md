## Locked rule

On each new completed XNG D1 bar, identify the current and preceding framework
`PERIOD_W1` calendar keys. Evaluate only when those keys differ and the current
key has not already been persisted as attempted.

Load exactly `strategy_vol_lookback * 5 + 5` completed XNG D1 bars. With the
Q02 defaults this is 205 bars. Require strictly descending timestamps,
positive finite closes, and positive tick volume.

```text
weekly_return = Close[latest completed] / Close[five bars earlier] - 1
current_volume = sum(tick_volume over latest five completed bars)
baseline_j = sum(tick_volume over prior non-overlapping five-bar window j)
percentile_rank = 100 * count(baseline_j <= current_volume) / 40

SELL when percentile_rank >= 75 and weekly_return > 0
BUY  when percentile_rank >= 75 and weekly_return < 0
FLAT otherwise
```

Persist the attempted week before history, signal, news, spread, quote, sizing,
or order gates. Use one `RISK_FIXED=1000` XNG position, a frozen
`2.5 * ATR(14,D1)` hard stop, no take-profit, a 600-point spread ceiling, and a
five-completed-D1-bar maximum hold. Standard news handling and Friday close
remain enabled. Do not retry within the same week after a stop, blocked entry,
or broker rejection.
