# Decision: Q02 PF hard bottom 1.20 -> 1.10

- Date: 2026-07-25
- Status: accepted (executed)
- Owner: OWNER (ratified in chat, 2026-07-25: "Q02_PF_MIN senken wir auf 1.1")
- Affected: `framework/scripts/p2_baseline.py` (`Q02_PF_MIN`)
- Relation to DL-082 §4: complementary. DL-082 introduced the evidence-conditional floor
  and already set its `hard_bottom_pf` to 1.10; this aligns the standalone constant with it.

The constant's old comment read "profit factor HARD BOTTOM (per symbol); never softened
below this". OWNER overrode that deliberately. Recorded here rather than argued.

## What the change actually does

**It changes no verdict.** This is the honest result and it is the reason this record exists.

Since DL-082 §4 (2026-07-19) the operative Q02 PF floor is

```
effective_floor(N) = max(Q02_EVIDENCE_FLOOR["hard_bottom_pf"], curve(N))
```

with `hard_bottom_pf` **already 1.10**. `Q02_PF_MIN` survives in exactly two places:

1. the fallback in `evidence_conditional_pf_floor` when the cfg omits `hard_bottom_pf`
   (it does not) or when the curve is disabled (it is not), and
2. the `hard_bottom=` field of the `pf_below_q02_floor` reason string — which was
   therefore **reporting 1.20 as the hard bottom while the code enforced 1.10**.

So the change removes a false statement from the evidence trail and corrects a dormant
fallback. Verdict impact: zero.

A stale comment on the gate itself was corrected in the same commit: it claimed the floor is
"never lowered below 1.20", contradicting `max(1.10, curve)` five lines above it.

## Why the number is so small — the PF floor is not the binding gate at Q02

Gate order in `_verdict_for_symbol` is trades-floor **before** PF-floor. The trades floor is
`max(min_trades, Q02_TRADES_MIN)` where `min_trades = 5 * window_years` — about 45 for a
full-history window. Of the 1 288 unique Q02 FAILs with recorded metrics, **2** have n >= 45.
Everything else died at the sample-size floor, before PF was ever consulted.

The apparent large population of "PF failures" at low N is an artifact of the evidence curve,
which *raises* the floor steeply below the N=450 anchor (n=2 -> 9.42, n=61 -> 1.64, n=100 ->
1.47). Those items are sample-size casualties wearing a PF label.

Sensitivity, if shorter card windows put the effective trades floor lower than 45:

| trades floor assumed | items with 1.10 <= pf < floor(N) |
|---:|---:|
| 10 | 43 |
| 20 | 13 |
| 30 | 3 |
| 45 | 2 |

## Consequence

If the intent behind "PF floor 1.1" is to admit more candidates at Q02, this constant is not
the lever — the evidence curve and the 5/yr trades floor are. That is a separate gate-criteria
decision and is not taken here.
