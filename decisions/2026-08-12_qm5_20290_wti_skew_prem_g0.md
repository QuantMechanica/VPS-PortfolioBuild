## Locked Rule

At the start of broker month M, reconstruct the interval from the first day of
M-12 through the last instant before M. Select strictly increasing completed
D1 closes and form only returns whose start and end timestamps both lie in
that interval:

    r[d]  = ln(close[d] / close[d-1])
    mu    = mean(r[d])
    m2    = mean((r[d] - mu)^2)
    m3    = mean((r[d] - mu)^3)
    skew  = m3 / (m2^(3/2))

    signal = BUY  when skew < 0
             SELL when skew > 0
             FLAT when abs(skew) <= 1e-12 or state is invalid

Require all twelve expected broker-month keys, 180 through 280 returns,
positive finite closes, finite moments, and `m2 > 1e-12`. Do not include the
current month, a boundary-crossing return, a return ending after the formation
window, demeaning by any external benchmark, a fitted threshold, a
cross-sectional rank, a trend fallback, or score-sized risk.

The position uses one `RISK_FIXED=1000` budget and a frozen
`3.5 * ATR(20,D1)` hard stop, without take-profit. Close the prior position on
the first processed D1 bar of the next broker month before considering a new
entry. A forty-calendar-day stale guard closes a missed rollover. Persist the
current month as consumed before history, signal, spread, quote, news, sizing,
or order checks; no failed or flat attempt retries within the month. Friday
close and both news axes are OFF. At most one position exists for the magic.
