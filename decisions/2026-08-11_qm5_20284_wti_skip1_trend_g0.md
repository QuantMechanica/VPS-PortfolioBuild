## Locked Rule

On the first processed `XTIUSD.DWX` D1 bar after a genuine broker-month
transition, reconstruct exactly fourteen consecutive completed broker-month
closes in reverse chronological order:

```text
M0  = close at end of month t-1  // deliberately skipped
M1  = close at end of month t-2  // trend endpoint
M13 = close at end of month t-14 // trend start

skipped_return = ln(M0 / M1)
trend_return   = ln(M1 / M13)

signal = BUY  when trend_return > 0
         SELL when trend_return < 0
         FLAT when trend_return == 0 or state is invalid
```

The newest endpoint must belong to the month immediately before the decision
month. Require positive finite closes, consecutive completed months, finite
returns, and strictly increasing endpoint chronology. `skipped_return` is
validated and logged but must not gate, confirm, reverse, size, or otherwise
alter the signal. There is no fallback to a return that includes `M0`, a
different horizon, moving average, rank, regression, vote, calendar direction,
external series, or prior pipeline result.

Consume and persist the decision month before history, signal, spread, quote,
ATR, sizing, news, or order gates. Close the prior package at the next genuine
month transition before considering replacement, even when direction is
unchanged. Each entry uses one `RISK_FIXED=1000` budget and a frozen
`3.5 * ATR(20,D1)` hard stop. The entry spread ceiling is 1,500 points. No
take-profit is authorized. Close after forty calendar days if normal monthly
rollover is missed. Friday close and both news axes are disabled.
