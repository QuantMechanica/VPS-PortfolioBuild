## Locked Rule

At the first processing of each broker D1 bar, use only completed bars and
define:

```text
C  = close[1]
H9 = max(high[1..9])
L9 = min(low[1..9])
XH = H9 - C
XL = C - L9
XX = max(XH, XL)
O  = open[0]
```

Require positive finite prices, `H9 > L9`, `XH > 0`, `XL > 0`, and strict
inequality between `XH` and `XL`.

- If `XH > XL`, the close is nearer the 9-day low: arm one day-only BUY STOP
  at `O + 0.66 * XL`, with hard SL at `entry - 1.32 * XX`.
- If `XL > XH`, the close is nearer the 9-day high: arm one day-only SELL STOP
  at `O - 0.66 * XH`, with hard SL at `entry + 1.32 * XX`.
- If the distances are equal, remain flat.

Cancel an unfilled prior-day entry when a genuinely new D1 bar arrives and
arm at most once per broker D1 bar. Consume that bar before quote, spread,
news, broker-distance, or order-send gates so rejection cannot be retried after
restart. If an opposite source setup triggers while a position is open, close
the existing position only; do not hedge or reverse in the same tick. Also
close after 20 completed D1 bars. Friday close and broker hard stops remain
binding. There is no take-profit, scale-in, grid, martingale, trailing stop,
volume signal, external feed, or adaptive parameter.
