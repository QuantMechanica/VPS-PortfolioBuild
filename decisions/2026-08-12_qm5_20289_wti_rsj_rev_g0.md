## Locked Rule

At the start of broker month `M`, load the strictly increasing completed D1
closes that define close-to-close returns wholly inside broker month `M-1`:

```text
r[d]     = ln(close[d] / close[d-1])
RV_plus  = sum(r[d]^2 for r[d] > 0)
RV_minus = sum(r[d]^2 for r[d] < 0)
RSJ      = (RV_plus - RV_minus) / (RV_plus + RV_minus)

signal = BUY  when RSJ < 0
         SELL when RSJ > 0
         FLAT when RSJ == 0 or state is invalid
```

Both close timestamps for every included return must belong to the same
immediately preceding broker month. Require 15 through 25 returns, positive
finite closes, finite arithmetic, positive total realized variance, and RSJ
inside `[-1,1]` within numerical tolerance. Do not include the current month,
an overnight return crossing the prior-month boundary, a return ending after
the prior month, or a fallback window.

The position uses one `RISK_FIXED=1000` budget and a frozen
`3.5 * ATR(20,D1)` hard stop, without take-profit. Close the prior package on
the first processed D1 bar of the next broker month before considering a new
entry. A forty-calendar-day stale guard closes a missed rollover. Persist the
current month as consumed before history, signal, spread, quote, news, sizing,
or order checks; no failed or flat attempt retries within the month. Friday
close and both news axes are OFF. At most one position exists for the magic.
