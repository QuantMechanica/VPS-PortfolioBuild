## Locked Rule

On the first processed `XTIUSD.DWX` D1 bar of a genuine broker-month
transition, reconstruct exactly thirteen consecutive completed broker-month-
end closes `C[0]..C[12]`, oldest to newest. The newest endpoint must belong to
the month immediately before the decision month. Define twelve chronological,
non-overlapping monthly log returns and the fixed two-per-tail Winsorized mean:

```text
r[i] = ln(C[i+1] / C[i]),                       i = 0..11
s = ascending copy of r

for i = 0..11:
  if i < 2:        w[i] = s[2]
  else if i > 9:   w[i] = s[9]
  else:            w[i] = s[i]

winsor_mean = sum(w[0..11]) / 12
```

Require positive finite closes, consecutive completed months, strictly
increasing endpoint timestamps, finite logarithms, ascending sorted state,
finite boundary values, exactly two replaced observations per tail, and no
endpoint from the current broker month. Buy when `winsor_mean > 0`, sell when
`winsor_mean < 0`, and consume the month flat when it equals zero or any state
is invalid. The statistic's magnitude does not scale risk. There is no
fallback to a cumulative return, raw median, trimmed mean, pairwise
pseudomedian, sign count, vote, price slope, calendar direction, or prior

Consume and persist the decision month before history, signal, spread, quote,
