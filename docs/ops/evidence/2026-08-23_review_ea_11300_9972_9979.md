card's real-time `open_today - close_prev`, same quantity). ATR significance gate uses `QM_ATR(...,

D1 bars, matches. Gap-fill exit target: `gap_origin_close = iClose(shift = entry_bar_shift + 2)`

the *same* historical bar's close as the shift index advances one-for-one with elapsed bars, so
it is functionally equivalent to "captured at entry and held" (Build-EA Note (e)) without needing
