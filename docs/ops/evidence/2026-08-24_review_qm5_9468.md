## Confirmed defects (→ RECYCLE)
1. **F2 (correctness, material) — entry-only filter suspends the 3-day exit.**
   `OnTick` returns on `Strategy_NoTradeFilter()` (mq5:191-192) *before*
   `Strategy_ManageOpenPosition()` (mq5:194). Wide spread / warmup / invalid
   quote therefore silently suspends the card's primary fixed-horizon exit.
   Fix: make Friday-close + open-position management reachable independent of
   entry-eligibility filters; apply the spread filter only before a new entry.
2. **F3 (correctness) — cooldown incomplete / not restart-safe.**
   `g_last_exit_time` is set only on this EA's local time-stop/strategy close
   (mq5:139-146); server-side SL exits and framework closes do not update it,
   and it is never rebuilt from history (mq5:49). Re-entry can skip the required
   3-bar cooldown after a stop-out.
3. **F4 (contract) — SPEC contradicts the D1 build.** `SPEC.md` declares base
   TF `H1` (line 64) and "no strategy-specific inputs" (line 28) while the card
   is D1 and the MQ5 exposes 9 governed inputs. Regenerate the SPEC from card +
   MQ5.
4. **F5 (scope) — 13-symbol package exceeds card authority.** Card names
   `SP500.DWX` (backtest) + `NDX.DWX`/`WS30.DWX` (live parallel-validation); the
   delivered sets and 13 active magic rows add GDAXI/UK100/XAUUSD + 7 FX pairs
   with no card `target_symbols` field authorizing them. Restrict to the
   approved port or obtain an OWNER card amendment.
5. **F1 (hardening, low) — D1 execution contract undeclared.** `OnInit` omits
   `QM_FrameworkDeclareExecutionContract(PERIOD_D1,…)` and gating uses no-arg
   `QM_IsNewBar()` (=PERIOD_CURRENT, mq5:223). Low severity in the factory (sets
   pin D1) but only 157/3797 EAs declare the contract; declaring it fails closed
   on wrong-TF attachment.
