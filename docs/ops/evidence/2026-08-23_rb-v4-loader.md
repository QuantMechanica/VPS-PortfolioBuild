## Review fixes (2026-08-23, FIX_REQUIRED → applied)

Reviewer finding (P1): `_validate_v4_topology` only enforced name/evidence_role
byte-equality against the v3 source for Phase-1 gates (`gate.ordinal <= 8`).
Phase-2/3 mapped gates were checked for authority/runner only, so a genuine ROT
criteria drift slipped through: draft v4 `Q14` (v3 source `Q16`) had silently
changed the name to `Best-Settings Head-to-Head + Holdout` (a new holdout
criterion absent from v3 and from proposal §3) and dropped the evidence_role
incumbent suffix (`SEALED_..._INCUMBENT_Q10` → `SEALED_..._INCUMBENT`). With
`reuse_rule = REUSE_HASH_AND_CONTRACT_EQUAL`, a v3 `Q16` pass could later be
reused as a v4 `Q14` pass under different stated criteria.

Fixes applied:

- `gate_manifest.py`: dropped the `gate.ordinal <= 8` guard. The
  criteria-preservation check now asserts `authority`, `runner`, `name`, and
  `evidence_role` equality for **every** mapped gate whose v3 source is a real
  top-level v3 gate. The only exemption is the documented `Q09 <- Q10A` promotion,
  where the v3 source is a non-top-level evidence stage and resolves to `None`.
- `gate_manifest.py`: added `_v3_role_to_v4()`. The single tolerated evidence_role
  difference is the **mechanical incumbent-gate renumber** driven entirely by the
  authoritative `V4_CONTRACT_EQUIVALENCE` table (v3 `Q10` incumbent → v4 `Q11`),
  applied only to a trailing `_Q<NN>` token that names a real gate. Every other
  role is compared byte-for-byte. This honours the reviewer's `_Q10`→`_Q11`
  renumber instruction without opening the door to a semantic change.
- `config/gate_manifest.v4.draft.json`: reverted `Q14.name` to `Best-Settings
  Head-to-Head` (byte-exact to v3 `Q16`) and set `Q14.evidence_role` to
  `SEALED_BEST_SETTINGS_VS_BASELINE_AND_INCUMBENT_Q11` (v3 role with the incumbent
  reference renumbered `_Q10`→`_Q11`). No `+ Holdout` criterion is introduced; had
  a holdout been intended it would require a proposal §3 entry and an explicit
  OWNER ROT ratification, not a silent draft edit.
- `docs/ops/rebaseline/GATE_MANIFEST_V4_LINEAR_PROPOSAL_2026-08-23.md` §3: the
  `Q16 → Q14` row now records evidence_role `..._INCUMBENT_Q11` and states the
  name is byte-preserved with no holdout, so proposal and draft agree.
- `tests/test_gate_manifest.py`: added
  `test_v4_preserves_v3_criteria_for_every_mapped_gate` (asserts all 17 mapped
  gates preserve v3 name/authority/runner/renumbered-role and pins the fixed `Q14`
  values) and `test_v4_criteria_drift_from_v3_source_is_rejected` (proves the
  loader fails closed on the `+ Holdout` name, the dropped suffix, the stale
  `_Q10`, and an authority tamper). Updated the pinned draft digest.
