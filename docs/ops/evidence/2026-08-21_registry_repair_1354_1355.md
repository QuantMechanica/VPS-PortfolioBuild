## Symptom
`QM5_1354_woodie-cci-dual-h1` and `QM5_1355_williams-vix-fix-fx-h4` are built EAs
(`.ex5` + `.mq5` present under `framework/EAs/`) carrying ACTIVE magic rows in
`framework/registry/magic_numbers.csv` (`ea_id*10000+slot`, 8 slots each, reserved_by
Gemini 2026-08-10), but had NO row in `framework/registry/ea_id_registry.csv`. The
canonical sweeper (`sweep_enqueue_built_eas.py`) skips any EA with
`registry_status=None`, so both were permanently excluded from the pipeline funnel.
QM5_1354 additionally already had an ACCEPTED review (`review_ea` task `0c9d9f82`,
state PASSED / APPROVED) — the missing registry row was its ONLY remaining blocker.

## Root cause (systemic, not a one-off typo)
`git log --all -p -- framework/registry/ea_id_registry.csv` shows the 1354/1355 rows
were **never** present in any commit in history — they were not written-then-deleted,
they were never written at build time.

Both approved cards
(`D:/QM/strategy_farm/artifacts/cards_approved/QM5_135{4,5}_*.md`) carry the numeric
`ea_id` baked into their frontmatter and were originally REJECTED in the 2026-05-19
batch (missing `source_citation`), *before* the current `reserve_ea_ids` governance
path existed. They were later recovered under the OWNER R1 policy (2026-07-23),
G0-approved 2026-07-27, and Gemini built them + allocated ACTIVE magic rows 2026-08-10.

The systemic gap: `reserve_ea_ids` only **auto-allocates new** IDs and has **no path to
backfill a legacy card that already carries a pre-assigned ea_id**. Any pre-numbered
card recovered from the old rejected pool therefore gets a magic allocation at build
time but never gets an `ea_id_registry.csv` row — silently invisible to the sweeper.
This is a class defect in the ea-id reservation path, not unique to these two EAs
(see `unenqueued_eas_count` WARN below); fixing the writer is out of scope for this
ops task but is flagged here for the tooling owner.

## strategy_id derivation (evidence-based, not guessed)
The `strategy_id` column in `ea_id_registry.csv` equals each card's `source_id`.
Verified against a known-registered sibling of the same source family: card
`QM5_1490_raschke-anti-pullback-reversal-h4.md` has `source_id:
6e967762-b26d-59a3-b076-35c17f2e7c36`, and its registry row carries the identical
value in the strategy_id column. Both 1354 and 1355 cards carry
`source_id: 6e967762-b26d-59a3-b076-35c17f2e7c36` (source: forexfactory-trading-systems;
the dominant "Development" indicator-EA family, 486 rows).
