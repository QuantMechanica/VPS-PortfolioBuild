# Website v5 — Astra critique and local funnel implementation

Review date: 2026-09-05 UTC. Task 90ca3dc0-3137-4a22-8179-450170069b4e; shared funnel delivery for 2de2ad78-5327-4e4e-9eea-13f82ac9ffd8. **REVIEW: local draft implemented; surrounding-page refinement proposal unapplied.** No deployment or deploy-repository commit.

The v5 implementation already gives QuantMechanica a coherent editorial voice. The cool paper, deliberate type pairing, quiet record rows, and light chart frames belong together. The remaining weakness is composition: the hero starts on a different axis from the evidence, the six statistics fall into an accidental four-plus-two arrangement, and the archive still spends too much vertical space per result. The old funnel also overstated what its census could prove. The replacement addresses that component now; the attached proposal makes the other choices concrete for the CEO review.

## Funnel delivery

The [design memo](2026-09-05_funnel_astra_design.md) was written before implementation. The final [20,404-byte script](2026-09-05_design_v5_astra_critique/qm-funnel.js) uses no external library; [its unified diff](2026-09-05_design_v5_astra_critique/qm-funnel.diff) is against the frozen original. Three phase headers, eighteen screen/label/count columns, an expandable register, and a keyboard-accessible Pause/Play control are visible in the draft. At 800px the expanded register is a single column; below 700px the canvas scrolls inside a labelled region while the page remains contained.

The public census is the only source for counts. Q02–Q08 trace thinning uses recorded clearances divided by strategies tested, with deterministic stratified sampling. It is an aggregate illustration with a finite display population, not an exact simulation of individual histories. No probabilities are derived from Q00/Q01 or from Q09 onward. Continuing traces in the latter phases demonstrate the process; they do not assert Q17 clearance. All zeroes remain zero. Eight qualified pairs, against a target of twenty-five, are explicitly a different unit from distinct strategies. If a future validation census ceases to decrease, the component switches its explanation to illustrative-only motion instead of silently clamping the data.

The runtime contract remains: container `data-src` fetch; `QMFunnel.mount`; an accessible image description; a hidden native census table refreshed from fetched data; stat-grid updates from the same source; localStorage pause persistence; DPR/resize handling; and IntersectionObserver/page-visibility suspension. Invalid input leaves a visible static fallback on initial load; a rejected remount preserves the current valid instance. The proof below covers malformed remount rejection; network-failure fallback was reviewed in the code, not fault-injected into the served draft.
