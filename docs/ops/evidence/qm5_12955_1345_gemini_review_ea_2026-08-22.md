## QM5_1345 — "Chan COT Speculator Momentum"

- `mq5` SHA256 verified locally: `99cf42d0a60d3857be1189c14429b9f71649b7f512851add410016de37b94dbf`
  — matches build artifact. Compile log: `0 errors, 0 warnings`.
- Magic base `13450000` = `1345 * 10000 + 0`; registry rows
  `framework/registry/magic_numbers.csv:16434-16446` cover 13 symbols
  (GDAXI/NDX/SP500/UK100/WS30/XAUUSD/EURUSD/GBPUSD/USDJPY/USDCHF/AUDUSD/
  USDCAD/NZDUSD.DWX, offsets 0-12), all `active`.
- **Primary defect — signal is not COT data, contrary to the approved card
  and its own source citation.** The approved card
  (`D:/QM/strategy_farm/artifacts/cards_approved/QM5_1345_chan-cot-spec-momo.md`,
  sourced from Ernest Chan's COT blog post) specifies: `ratio =
  non_commercial_longs / max(non_commercial_shorts, 1)` computed from
  **CFTC Commitments of Traders reports** (weekly, non-commercial futures
  positioning), with entry at ratio>=3.0 / <=1/3 and exit at ratio crossing
  1.0. The card's own R3 evaluation table explicitly flags this as
  `UNKNOWN — Needs deterministic CFTC COT ingestion and accepted mapping
  from futures positioning to DWX CFD symbols`.
  The shipped `.mq5` (`Strategy_CalculateRatio()`, lines 60-86) does **not**
  ingest COT data anywhere — there is no CFTC file read, no external
  positioning input, no weekly-cadence gating. Instead it sums positive vs.
  negative `iClose` bar-to-bar deltas over `strategy_lookback_period=60`
  daily bars and takes their ratio — a pure price-momentum proxy. The
  entry/exit numeric thresholds (3.0 / 0.333 / 1.0) were copied from the
  card verbatim onto this unrelated quantity, and the code comment block
  (lines 7-16) relabels the source as "Ernest Chan COT / directional
  volume-flow momentum" — blurring a full substitution of the cited
  strategy's core signal into a generic momentum ratio never validated
  against the source. This is a mechanization defect, not a faithful
  implementation: the strategy's edge thesis (COT positioning extremes lead
  price) is not what is being tested; a same-instrument momentum-ratio
  thesis is being tested under the COT strategy's name, citation, and card
  ID.
- **Secondary defect — symbol universe deviates from the card.** The card
  body names only `XAUUSD.DWX` and/or `OIL.DWX` as the draft DWX port
  target (frontmatter has no `target_symbols` field to override this). The
  shipped registry/build instead spans 13 symbols including 5 equity
  indices (GDAXI/NDX/SP500/UK100/WS30) and 7 FX majors, none of which have
  any stated COT/CFTC linkage in the card, and drops `OIL.DWX` entirely.
  Given the price-only proxy substitution above, this reads as a generic
  momentum EA built across a broad universe under a COT-specific card,
  rather than the narrow instrument set the source strategy requires.
- Inputs are otherwise correctly wired (`strategy_lookback_period`,
  `strategy_ratio_entry_long/short`, `strategy_ratio_exit`,
  `strategy_atr_period/atr_sl_mult`, `strategy_max_hold_days`,
  `strategy_max_spread_points` all read at a use site — no dead inputs),
  `req.symbol_slot` wired correctly, `qm_news_stale_max_hours=336`,
  backtest set files use `RISK_FIXED=1000`/`RISK_PERCENT=0` correctly, no
  ML/grid/martingale, one-position-per-magic. These are the only respects
  in which this is a clean V5 EA.

**Verdict: correctness defect found — FAIL-leaning.** The EA does not
implement the approved card's cited strategy; it implements a different,
undisclosed price-momentum signal reusing the card's numeric thresholds and
identity. This should not proceed past Codex review without either (a) a
corrected card that honestly describes a price-momentum-ratio strategy
divorced from the COT/CFTC source and re-run through R1-R4, or (b) a real
CFTC COT ingestion path per the original card. Recommend RECYCLE, not
APPROVED, once Codex confirms.
