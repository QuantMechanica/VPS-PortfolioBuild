### Why 31.00579%, not the report's 25.28%

The summary's parsed run row records drawdown money `31,005.79` and the native
report string `31 005.79 (25.28%)`. Q10 imports `STARTING_EQUITY = 100_000.0`
from `framework/scripts/q05_stress_medium.py` and calculates:

```text

```

It then compares that value to `DD_PCT_MAX = 25.0`. This is the sole Q10
failure. Substituting the report's peak-relative percentage would change the
declared gate and is not permitted in this ticket.

Only option **(b)** is recommended.

history repair and immutable Q09 binding**.

1. Pin the intended candidate EX5. If the candidate is the canonical build,

3. Run an append-only Q02-through-Q08 chain on that EX5 and the deterministic

There is no honest existing one-line Q10 enqueue command: it would bypass the
defects above. This ticket intentionally supplies none.
