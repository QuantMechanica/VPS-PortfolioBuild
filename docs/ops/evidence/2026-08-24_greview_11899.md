## Findings requiring RECYCLE

### F1 — mandatory news liquidation is not implemented

The card requires every position to close 15 minutes before scheduled high-impact EUR, USD, or GBP news (`...cards_approved/QM5_11899_psar-ao-ac-confluence-h1.md:81-82`). The delivered EA instead:

- defaults every news axis OFF/NONE (`QM5_11899_psar-ao-ac-confluence-h1.mq5:21-26`);
- implements `Strategy_NewsFilterHook` as unconditional `false` (`:214`);
- calls the generic news permission check at `:240-245`, which only returns from OnTick and never closes a position;
- places that return before management and strategy exits (`:250-252`), so an activated Q09 news mode can suppress normal exits during its blackout;
- passes `_Symbol` to the framework filter (`:242-244`), while framework relevance is base/quote-symbol scoped (`framework/include/QM/QM_NewsFilter.mqh:448-479`), not the card's fixed EUR+USD+GBP calendar scope.

The framework's `QM_NEWS_TEMPORAL_CLOSE_ALL_PRE` entry-side implementation is explicitly only a 30-minute admission block; its close side remains TODO (`framework/include/QM/QM_NewsFilter.mqh:1230-1234`). Therefore selecting that mode would neither implement the card's 15-minute interval nor liquidate positions.

**Named fix:** implement the card's 15-minute high-impact EUR/USD/GBP owned-position close in `Strategy_NewsFilterHook`; keep management/exits reachable through entry blackouts by moving the generic entry-only news gate to the canonical location after management and strategy exits; generate governed setfiles with the required active news configuration.

### F2 — MAE sampling is after an early-return guard

The EA calls `QM_KillSwitchCheck()` before `QM_FrameworkTrackOpenPositionMae()` (`QM5_11899_psar-ao-ac-confluence-h1.mq5:235-236`). An active kill switch therefore skips open-position MAE sampling. The canonical skeleton requires MAE sampling before any per-tick guard (`framework/templates/EA_Skeleton.mq5:175-181`).

**Named fix:** move `QM_FrameworkTrackOpenPositionMae()` ahead of `QM_KillSwitchCheck()`.

### F3 — the H1 new-bar edge is consumed twice

With an owned open position and `strategy_alt_exit=true`, `Strategy_ExitSignal()` consumes `QM_IsNewBar(_Symbol, strategy_signal_tf)` at `QM5_11899_psar-ao-ac-confluence-h1.mq5:193`. OnTick then calls the same stateful key again at `:264` before evaluating the mirror entry. `QM_IsNewBar` stores the first observed edge and returns false to a second same-key call (`framework/include/QM/QM_Indicators.mqh:156-176`). A reversal exit and opposite confluence on one H1 boundary can therefore close the old trade while suppressing the card's mirror entry on that signal bar.

**Named fix:** compute the H1 new-bar edge once per tick and share the cached result between exit and entry evaluation.

### F4 — 96 bars are implemented as 96 elapsed hours

The card says to close at H1 bar 96 (`...cards_approved/QM5_11899_psar-ao-ac-confluence-h1.md:83`). The EA compares `TimeCurrent()-opened` with `96 * PeriodSeconds(H1)` (`QM5_11899_psar-ao-ac-confluence-h1.mq5:185-190`). Weekends and market closures advance elapsed time without completing H1 bars.

**Named fix:** derive the timeout from completed `strategy_signal_tf` bars since entry, with restart-safe reconstruction from the position open time.
