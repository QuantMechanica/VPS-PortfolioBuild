## Card-fidelity findings

The basic King Keltner mechanism is present:

- Card lines 74-77 require closed-bar SMA(Typical, 20) and a 1.5 x ATR(10)
  envelope. Source lines 99-110 calculate those values at shifts 1/2.
- Card lines 90-99 require the channel breakout plus MA slope, 2 x ATR stop,
  2R target, and midline exit. Source lines 117-139 and 154-173 implement those
  rules.
- Card lines 85-88 require spread, rollover, daily-loss, and one-position
  entry filters. Source lines 68-77 implement the spread test and lines 96-97
  enforce one open position.

The build is nevertheless not card-faithful enough for Q02:

1. **Card loss/drawdown controls are absent.** The approved card requires a
   2.0% daily-realized-loss entry halt (line 87), a 2.5% daily drawdown hard
   stop, and a 5.0% total drawdown stop (lines 111-114). Source
   `Strategy_NoTradeFilter` (lines 61-80) implements none of them. The inherited
   legacy framework call is not equivalent: `QM_Common.mqh:296-298` configures
   the entry deviation as 20 points and initializes the kill switch with
   `3.0, 0.0, 1.0`. The read-only hardening check reports three
   `EA_CARD_LOSS_LIMIT_MISMATCH` failures.

2. **The GMT rollover rule uses broker time.** Card line 86 specifies
   23:55-00:05 GMT. Source lines 63-66 derive HHMM directly from
   `TimeCurrent()` without `QM_BrokerToUTC` or another governed DST conversion.
   The read-only hardening check reports
   `EA_BROKER_TIME_USED_FOR_GMT_WINDOW`.

3. **News blackouts suppress mandatory exits.** Source lines 211-216 return
   when the central news filter blocks trading, before the Friday close at line
   218 and before the card's midline exit at lines 229-239. Thus an existing
   position cannot execute either exit during a news blackout. The canonical
   entry-only placement is documented in
   `framework/templates/EA_Skeleton.mq5:192-225`.

4. **The no-trade filter also suppresses exits and fails open on missing spread
   data.** Source line 219 returns before `Strategy_ExitSignal`. Both the
   rollover blackout and the spread test can therefore disable the card exit.
   In addition, source lines 72-79 return `false` when ATR, quote, or point data
   are invalid, allowing entry evaluation without the mandatory spread filter.

5. **The card's three-tick slippage cap is not implemented.** Card line 114
   requires at most 3 ticks. The EA has no matching input/override, while the
   legacy framework initializer passes 20 points to `QM_EntryConfigure`
   (`framework/include/QM/QM_Common.mqh:296`). Those units are not a portable
   equivalent across SP500, XTIUSD, and EURUSD.

6. **H4 execution identity is not fail-closed.** The card fixes H4 at lines
   37-39 and 221-225. Indicator reads use `PERIOD_H4`, but source line 221 calls
   the default `QM_IsNewBar()` tied to the attached chart and `OnInit`
   (lines 188-197) does not reject a non-H4 attachment. A non-H4 host therefore
   changes signal-evaluation cadence while continuing to read H4 values.

These defects are actionable and repairable, so `RECYCLE` is appropriate rather
than `FAILED`.
