## Confirmed defects (card-faithfulness + correctness)

### D1 (Critical, card-faithfulness) — period detector is not the approved Ehlers 2013 Autocorrelation-Periodogram
`QM5_1624_ehlers-adaptive-cg-h4.mq5:66-119` (`ComputeDominantPeriod`).
The approved card requires "Ehlers 2013 Autocorrelation-Periodogram (deterministic closed-form)…
DFT-on-autocorrelation per Ehlers 2013 ch. 8 algorithm pseudo-code reproduced verbatim".
The implementation instead:
- uses UNCENTERED cosine similarity of raw close levels
  `sum(x*y)/sqrt(sum(x²)·sum(y²))` (`:84-92`) — no mean subtraction / no highpass-roofing
  detrend, so it is not the Ehlers/Pearson correlation;
- runs an unsmoothed sine/cosine sum over those values (`:105-111`) with NO power
  normalization/smoothing;
- selects the period by bare argmax of raw power (`:112-116`) rather than the
  center-of-gravity of the normalized spectrum.
On trending price the large DC component keeps uncentered correlations near 1 across all
lags, so `P` can lock to a boundary/spectral artifact. `P` drives the CG window `N=P/2`,
entries, exits, cooldown and time stop, so this is a materially different mechanism under
the approved EA ID. Required: port + fixture-test the canonical detector against known
input/output vectors.

### D2 (High, correctness) — `2×P` time stop counts wall-clock seconds, not H4 bars
`:267-275`. `TimeCurrent() - opened >= time_stop_bars * PeriodSeconds(PERIOD_H4)` counts
weekend/holiday/halt hours as bars that never traded, so the hold shortens unpredictably
across calendar gaps. Card specifies actual H4 bars. Required: count completed H4 bars
since entry from validated series history.

### D3 (High, determinism) — entry period `P` is not restart-durable
`:51,250,269`. `g_last_dominant_period` defaults to 20 and is set only when this process
emits the entry. On EA/terminal restart with a live position the entry binding is lost and
the time stop silently becomes 2×20=40 H4-equivalent hours. Required: seal entry `P` to
durable position provenance or define an approved deterministic recompute rule.

### D4 (Medium, correctness) — cooldown state committed before order acceptance
`:248-250` set `g_last_trade_time/dir/period` BEFORE `QM_TM_OpenPosition` runs (`:411`).
A rejected order still starts cooldown and mutates future state despite no trade; a
restart clears cooldown entirely. Required: update from a confirmed accepted entry, made
restart-recoverable.

### D5 (Low, robustness) — H4 execution scope not fail-closed
No `_Period == PERIOD_H4` guard in `OnInit` (`:328-350`); the new-bar clock is
`QM_IsNewBar()` on `PERIOD_CURRENT` (`:401`). Signal reads are explicitly bound to
`PERIOD_H4` (`:196,223`) and all 14 setfiles are H4, so impact is bounded in practice, but
a wrong chart changes evaluation cadence without changing identity. Recommended: reject
non-H4 init or bind the new-bar clock to H4.
