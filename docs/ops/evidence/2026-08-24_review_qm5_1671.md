## Confirmed defects (file:line)

1. **Dead outside-band period gate (mechanism-breaking).** `AdvanceCycleState()` clamps the
   extracted period into `[strategy_period_min, strategy_period_max]` at
   `.mq5:164-168` before the admission test at `.mq5:288`
   (`period_ok = g_cycle_period >= min && <= max`). After the clamp this condition is
   tautologically true, so the card-mandated "reject when cycle_period outside [10,48]"
   (card `docs/strategy_card.md`, Mechanik/`period_ok`) never fires. A too-short/too-long
   dominant cycle is relabelled to exactly 10 or 48 and admitted. Additionally an
   undetectable phase (`delta_phase <= 0.01`) defaults `raw_period = 20.0` (`.mq5:160`) —
   admitted, not marked unavailable. Fix: keep the raw period validity separate; clamp only
   presentation, reject the out-of-band/undetectable admission value.

2. **Time-stop not bound to the entry period.** Card: time-stop = `1.5 × cycle_period`
   where the period was **extracted at entry**. `Strategy_ExitSignal()` uses the live global
   `g_cycle_period` (`.mq5:432`), which `AdvanceCycleState()` recomputes every closed H4 bar,
   so the horizon drifts after entry and a restart resets it to 20. Fix: seal the entry period
   into durable position provenance and use that immutable value for the position lifetime.

3. **Hilbert quadrature is not the named 4-tap FIR.** Card R2/R4 bind a fixed Ehlers 4-tap
   FIR Hilbert transform (`docs/strategy_card.md` R2/R4 reasoning). The EA computes quadrature
   as a 2-point centered difference `quad0 = (filt[0]-filt[4])/4.0` (`.mq5:145`; same
   substitution for the EBSW component at `.mq5:172`). This changes phase, amplitude, inferred
   period and every downstream zero-cross/exit decision. Fix: implement the named fixed-tap
   transform and verify against deterministic reference vectors.

4. **News blackout suppresses exits and state accounting.** `OnTick()` returns on
   `!news_allows` (`.mq5:512`) before `Strategy_ManageOpenPosition`, `Strategy_ExitSignal`,
   Friday-close and `AdvanceCycleState`. A news pause therefore also pauses risk exits and
   drops closed-bar observations feeding the 3-consecutive-bar amplitude-collapse rule. Fix:
   keep news mandatory for new entries only; allow management, strategy exits, Friday close and
   closed-bar accounting during blackout.

5. **Cooldown consumed before order acceptance (minor).** `g_last_trade_dir` /
   `g_last_trade_time` are set inside `Strategy_EntrySignal` (`.mq5:328-329, 352-353`) before
   `QM_TM_OpenPosition` runs in `OnTick`; a rejected order still consumes the cooldown, and the
   globals are restart-volatile. Fix: advance cooldown from confirmed-entry evidence.
