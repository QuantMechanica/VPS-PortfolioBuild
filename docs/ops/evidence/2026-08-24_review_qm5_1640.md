## Blocking fidelity defects (actionable)

1. **Cross-sectional top-5 ranking is absent — strategy identity change.** Card (docs/strategy_card.md, Entry): "compute `ROC_12_0`… Rank instruments descending… Hold equal-risk long exposure in the top five instruments with positive `ROC_12_0`." The EA runs per-chart and admits *every* symbol whose own ROC>0 (`Strategy_EntrySignal`, mq5:140-181; `Compute12MonthROC`, mq5:108-118). Grep confirms the EA reads **only `_Symbol`** — no `iClose`/`SymbolInfo` on any other symbol — so it cannot rank the basket or enforce the five-slot cap, and it exits only when a symbol's own ROC turns non-positive rather than when it leaves the top-5. This is implementable in a single-chart EA (read `iClose(otherSymbol,…)` for the approved basket, admit only if `_Symbol` ∈ positive top-5); the builder did not. Absolute per-symbol momentum ≠ cross-sectional momentum. **Primary RECYCLE cause.**

2. **Same-month re-entry after stop-out.** Card is a monthly rebalance. `Strategy_EntrySignal` blocks re-entry only while a position is open (`SelectOurPosition`); after a stop-out it re-enters on any later new bar in the same month while ROC>0. `g_last_rebalance_key` is set (mq5:178) but never used as an entry guard. Guard entry to one admission per rebalance month.

3. **Universe expansion beyond the card basket.** 13 registered/set-generated symbols include 7 FX/metal instruments (AUDUSD, EURUSD, GBPUSD, NZDUSD, USDCAD, USDCHF, XAUUSD) that are off-thesis for an industry/index-momentum card; the card's index/sector proxies FCHI, SPA35, NETH25, STOXX50E are absent. Bind generation to the approved, availability-checked index/sector proxy basket and record the rankable universe in durable evidence.

4. **Spread filter is fail-open and a different statistic (minor).** `SpreadAllows` returns `true` when `atr_val<=0` (mq5:68-70) and gates on `0.3×ATR(20,D1)`; card specifies skip when spread > `2.5×` 20-day median spread. Use the specified median statistic and fail closed when unavailable.

Only the min-bars floor is short — `strategy_min_daily_bars=260` (~12.4 mo) vs the card's 14 completed months (~294 D1 bars); raise the floor rather than switch to MN1.

Worth fixing so strategy exits stay live, but not blocking on its own.
