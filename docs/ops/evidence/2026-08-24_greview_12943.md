### 2. Entry-only filters can suppress required exit management

The card describes spread filtering as "skip if spread > 3 pips at signal
time" and the optional Asian-session rule as "no trades" during 00:00-07:00
(`card:78-82`). `Strategy_NoTradeFilter()` implements both filters
(`mq5:54-76`), but `OnTick` returns on that function at `mq5:275`, before
`Strategy_ManageOpenPosition()` at `:277` and before the opposite-crossover
exit path at `:279-302`.

Consequently, a wide spread can defer both the 96-bar break-even time stop and
an opposite-signal exit. Enabling the deferred Asian filter would also disable
those exits throughout the session. Those are invented exit restrictions, not
card-declared entry filters.

Action: keep kill-switch/Friday-close/MAE ordering intact, run management and
exit logic regardless of the entry filters, and apply the spread/session
predicate only before new entry evaluation. Add a regression proving an open
position remains manageable while either entry filter blocks entries.
