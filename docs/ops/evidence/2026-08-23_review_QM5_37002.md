## Defects requiring RECYCLE

### 1. High — approved drawdown contract not enforced
Card §4.2 mandates daily hard stop 2.5% and total DD stop 5.0% (§3.1.3 also a 2.0% daily
circuit breaker). `OnInit` (mq5:262-283) calls only `QM_FrameworkInit`, whose default is
`QM_KillSwitchInit(ea_id, magic, 3.0, 0.0, 1.0)` (`framework/include/QM/QM_Common.mqh:298`)
— daily 3.0% (wrong number) and total DD **disabled (0.0)**. No explicit
`QM_KillSwitchInit(qm_ea_id, QM_FrameworkMagic(), 2.5, 5.0, 1.0)` override exists, unlike
remediated siblings (`QM5_36004.mq5:442`, `QM5_36001.mq5:395`). **Fix:** add the explicit
kill-switch init in `OnInit`.

### 2. High — OnTick gates protective exits behind the entry filter
`Strategy_NoTradeFilter()` early-returns at mq5:305-306, *before*
`Strategy_ManageOpenPosition()` (308) and `Strategy_ExitSignal()` (310). During the
rollover blackout or a wide-spread window an open position can neither be managed nor
exited — the opposite-trigger exit and the time-stop are suspended exactly when protection
matters. **Fix:** run `Strategy_ManageOpenPosition`/`Strategy_ExitSignal` before
`Strategy_NoTradeFilter`.

### 3. Medium — exit/risk geometry substituted, not card-traceable
Card §3.4 specifies SL at the opposite trigger boundary (or entry ∓ 0.50×Range) plus an
explicit "close all before daily settlement" EOD exit. Code instead uses a 2.0×ATR(14) hard
stop (`QM_StopATR`, mq5:180/186 — constants 14/2.0 absent from card §6.1's parameter table)
and a 5-bar max-hold time-stop (mq5:242-248, also not in the card); no EOD close.
`Strategy_ManageOpenPosition` is empty (mq5:199), so the card's BE/trailing state machine
(§5) is unimplemented. Card also implies ~1:1.5 R:R with a computed TP; code sets
`req.tp=0.0`. **Fix:** reconcile against card §3.4 — implement range-based SL + EOD close, or
have the card amended to ratify the ATR-stop + time-stop design as an intentional gap.

### 4. Low — rollover blackout uses broker time labelled as GMT
`IsRolloverBlackout()` (mq5) builds the 23:55-00:05 window from `TimeGMT()`, which in the
Strategy Tester models broker/server time (Darwinex UTC+2/+3), not true GMT — same class as
the QM5_37001 review. The framework news gate converts internally via `QM_BrokerToUTC`; only
this local rollover check bypasses it.

closed-bar mechanization of Dual Thrust, lookahead-free; flag for the card author but not a
blocker on its own.
