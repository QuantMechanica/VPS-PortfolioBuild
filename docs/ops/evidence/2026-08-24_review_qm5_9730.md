## Defects (actionable)

1. **[RECYCLE] Invented spread filter can suppress mandatory exits.**
   `strategy_spread_max_atr=0.30` (mq5:48) is applied in `Strategy_NoTradeFilter()`
   (mq5:66-68). The card §"Additional filters" authorizes only incomplete-D1/W1-bar
   skips — no spread/ATR gate. Sibling `QM5_9576` documents the convention explicitly
   (`QM5_9576...mq5:90`: "the approved card declares no custom time or spread gate").
   Because the canonical OnTick template gates `Strategy_ManageOpenPosition()` (mq5:201)
   and `Strategy_ExitSignal()` (mq5:203) behind `Strategy_NoTradeFilter()` (mq5:198),
   a wide-spread bar can delay the 10-day time stop and both RSI exits on an open
   position. Fix: remove the unapproved spread filter, or restructure so exits are
   reachable independent of entry eligibility.

2. **[RECYCLE] Delivered 13-symbol package exceeds the approved index-only universe.**
   Card R3/body scopes SP500.DWX (backtest) + NDX.DWX, WS30.DWX (live) — index family
   only. Delivery registers 13 magic slots (`framework/registry/magic_numbers.csv`,
   slots 0-12) and emits 13 setfiles adding GDAXI, UK100, XAUUSD and seven FX majors —
   a different instrument class than the approved mean-reversion-on-indices card. Card
   universe is ROT; a build cannot expand it unilaterally. Fix: restrict to the approved
   index cohort or obtain an OWNER card amendment with an explicit `target_symbols`
   contract.

3. **[RECYCLE, minor] Valid RSI == 0 dropped as missing data.**
   `Strategy_EntrySignal()` rejects when `rsi3_w1 <= 0.0 || rsi2_d1 <= 0.0` (mq5:87).
   RSI can legitimately equal 0 after an uninterrupted decline — the strongest possible
   satisfaction of the card's `W1 RSI(3) <= 20` / `D1 RSI(2) <= 10` entry conditions.
   The implementation discards this valid edge instead of distinguishing an indicator
   read-failure from a valid zero. (`Strategy_ExitSignal()` mq5:146-151 already handles
   this correctly with per-value `> 0.0` guards.) Fix: use an indicator validity proof
   that admits the closed-form RSI range [0, 100].
