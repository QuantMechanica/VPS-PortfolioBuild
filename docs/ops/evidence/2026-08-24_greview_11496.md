## Blocking findings

### 1. The card's no-Friday-entry rule is absent

The approved card explicitly requires `No Friday entry` at card line 89. The EA's
strategy filter always returns `false` at MQ5 line 95, and the entry function at lines
97-180 has no weekday check. The only Friday call is
`QM_FrameworkHandleFridayClose()` at line 222. That framework function is an end-of-day
close/block beginning at the configured broker hour, not an all-Friday entry ban
(`framework/include/QM/QM_Common.mqh:649-661,938-956`). Thus entries before 21:00 broker
time on Friday remain possible.

**Named fix:** add and use a card-faithful Friday-entry guard (normally a declared
`strategy_no_friday_entry` input defaulting `true`, checked via broker
`day_of_week == 5` before entry), then regenerate governed artifacts and recompile through
`COMPILE_EA`.

### 2. The stop uses the signal-bar PSAR, not the card's entry-bar PSAR

The card distinguishes the signal PSAR at shift 1 (card lines 60-68) from the stop's
"first SAR dot at entry" at shift 0 (card lines 72,77-78 and implementation note line
109). The EA reads only `psar_1 = QM_SAR(..., 1)` at MQ5 line 113 and reuses that value
for both long and short stops at lines 151 and 159. It never reads shift 0 for the stop.

**Named fix:** retain shift 1 for signal confirmation, read and validate a separate
entry-bar PSAR with `QM_SAR(..., 0)` for SL construction, and recompile through governed
`COMPILE_EA`.

### 3. The news control is executable but disabled by all delivered defaults

The news calls are present at MQ5 lines 215-220, so this is not missing wiring. However,
the delivered defaults set temporal mode `OFF`, compliance `NONE`, and legacy mode `OFF`
at lines 22-26; none of the three setfiles overrides them. The V5 skeleton's standard
defaults are `QM_NEWS_TEMPORAL_PRE30_POST30` and `QM_NEWS_COMPLIANCE_DXZ`
(`framework/templates/EA_Skeleton.mq5:51-62`). The card supplies no news-OFF exemption.

**Named fix:** restore the standard two-axis defaults, or obtain a durable card/OWNER
exemption that explicitly authorizes news OFF; regenerate setfiles and recompile via
governed `COMPILE_EA`.

### 4. Required Q01 `SPEC.md` is missing
