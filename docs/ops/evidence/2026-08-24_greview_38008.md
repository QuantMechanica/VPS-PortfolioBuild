The runtime sequence is nevertheless not card-faithful:

2. Closed-bar state is refreshed after management and after the spread filter. `Strategy_ManageOpenPosition()` runs at `mq5:321`, the filter reads cached `g_last_atr` at `:140-144`, and only then does `AdvanceState_OnNewBar()` refresh Close[1]/midline/ATR at `:355`. Thus the midline exit uses the prior cache (one D1 bar late in steady state), while restart state remains zero because `OnInit()` never seeds it (`:274-302`). A failed OHLC read returns without clearing the previous cache (`:92-110`). **Named fix:** bind a single new-bar decision to `_Symbol,strategy_signal_tf`, clear and refresh state fail-closed before management/admission, and seed/reconstruct the closed-bar state on initialization.

3. The approved market-order ceiling is 3 trade ticks (`card:110-113`). This EA never calls `QM_EntryConfigure`; the framework default is 20 points (`framework/include/QM/QM_Entry.mqh:63-88`, `QM_Common.mqh:296`). **Named fix:** convert three symbol trade ticks to deviation points and configure that fail-closed ceiling after framework initialization.
