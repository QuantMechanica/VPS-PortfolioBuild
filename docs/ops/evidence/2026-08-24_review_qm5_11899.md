## Independent verification of the 6 worker findings

**CONFIRMED (actionable):**

1. **QM_IsNewBar edge double-consumed (F4).** `QM_IsNewBar` is a latching per-(symbol,tf) tracker — first call on a new bar returns true and stores `last_bar_time`, subsequent calls return false (`framework/include/QM/QM_Indicators.mqh:161-164`). `Strategy_ExitSignal` consumes the edge at `…11899.mq5:193` when a position is open, and OnTick re-checks it at `…11899.mq5:264` to gate entry. On the bar where an alt-exit fires and closes the position, line 264 returns false and the mirror re-entry cannot be evaluated that bar. Real logic bug (narrow window). CONFIRMED.

2. **KillSwitch precedes the MAE hook (F5).** `…11899.mq5:235-236` calls `QM_KillSwitchCheck()` (early-return) BEFORE `QM_FrameworkTrackOpenPositionMae()`. Every sibling EA (QM5_10001/10025/10147/10305/10359/10403 …) calls the MAE tracker FIRST, then the kill switch. When the kill switch is active the Q08 open-position MAE sample is skipped for that tick — a deviation from the canonical V5 OnTick skeleton. CONFIRMED.

3. **News pre-close mechanism absent (F1).** Card Exit Rules require closing positions ≥15 min before high-impact EUR/USD/GBP news. Shipped defaults disable all news (`…11899.mq5:22-26`, all OFF/NONE), `Strategy_NewsFilterHook` is a no-op (`:214`), and the generic news call at `:240-245` is entry-admission only (`if(!news_allows) return;`) — it never closes open positions. The framework does expose `QM_NEWS_TEMPORAL_CLOSE_ALL_PRE` (mode 6, close 30 min before — `QM_NewsFilter.mqh:33`) but (a) it is not enabled in the governed backtest setfiles (no `qm_news_*` lines), (b) the OnTick pattern would still only block entry, not close, and (c) the mode's 30-min window ≠ the card's 15-min. Card news exit is unimplemented and the filter is fully inert as shipped. CONFIRMED (partly a fleet-wide framework-convention limitation, but the card mechanism is not delivered).

4. **Hard timeout is wall-clock, not completed H1 bars (F3).** `…11899.mq5:187-190` compares `TimeCurrent()-opened >= strategy_time_stop_bars * PeriodSeconds(tf)` = 96×3600 s wall-clock, so weekends/closures advance the timer without producing H1 bars; the card specifies "H1 bar 96". Minor deviation (the card's own "(4 days)" gloss shows author ambiguity), but a completed-bar count would be more faithful. CONFIRMED (minor).
