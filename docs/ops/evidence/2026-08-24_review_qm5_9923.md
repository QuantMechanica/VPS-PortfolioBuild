## Primary defect (actionable, blocks Q02)

**Framework `QM_HMA` drops the defining HMA outer smoothing.**
`framework/include/QM/QM_Indicators.mqh:586-604`.

Card mechanism (card lines ~11 and Build-EA Notes): `HMA(n) = WMA(2*WMA(close,
n/2) - WMA(close, n), sqrt(n))` — a four-step construction whose step 4 is the
outer `WMA(raw, sqrt(n))`. The card explicitly instructs the reviewer to confirm
the rounding/outer-smoothing convention is implemented consistently.

`QM_HMA` computes:
- `half = period/2`, `sqr = sqrt(period)` (line 591-592)
- `w_half = QM_LWMA(half)`, `w_full = QM_LWMA(period)` (597-598)
- `diff = 2*w_half - w_full` (599)
- `return diff;` (603)

Step 4 is missing entirely: it returns the raw Hull difference series and never
applies `WMA(diff, sqrt(period))`. `sqr` (line 592) is a **dead variable** — never
referenced after declaration. The in-code comment (lines 600-603) documents an
intended `LWMA/EMA(sqrt(period))` re-smoothing that is not performed. `QM_LWMA`
(562-566) is a correct `MODE_LWMA` weighted MA, so the WMA substrate is fine; only
the outer smoothing pass is absent.

Consequence: `hma_fast`/`hma_slow` at MQ5 lines 125-128 / 182-185 evaluate the
un-smoothed `2*WMA(n/2)-WMA(n)` series, so every long/short crossover entry
(136,155), opposite-cross exit (212,217), and the card's stated distinctiveness
vs TEMA/ZLEMA are all computed on the wrong indicator.

Not a pre-existing accepted state: the only two `QM_HMA` consumers (QM5_9923,
QM5_9961) have never reached beyond `COMPILE_EA` (DB read-only: rows only
`INVALID`/`COMPILE_FAIL`), so no HMA EA has ever passed Q02 with this primitive.

Fix owner: this is a shared-framework primitive, not the gemini EA body. Correct
`QM_HMA` to apply the final `QM_LWMA(diff-series, sqrt(period))` pass (needs a
custom-indicator or buffer-input path, as the code comment admits), then recompile
the HMA family (9923/9961) in an OFF window (recompile-in-inventory = ROT →
orchestrator routes to Codex + OWNER OFF window). Route as a framework fix, not a
gemini re-build.
