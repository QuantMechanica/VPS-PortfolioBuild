open new positions on Friday before 21:00. `SPEC.md:13-17` also drifted the card rule
to “standard Friday close.”

**Named fix:** implement a deterministic broker-time Friday entry block before
`Strategy_EntrySignal` (and document it faithfully in `SPEC.md`), while retaining
the framework Friday-close lifecycle. Then run the governed compile named in F1.
