## Actionable defects

### D1 (High) — mandatory exits are gated behind an entry-eligibility filter
`OnTick` runs `if(Strategy_NoTradeFilter()) return;` (line 180-181) BEFORE
`Strategy_ManageOpenPosition()` (line 183). Both mandatory exits — the RSI>=70 exit
and the 7-D1-bar time stop — live only inside `Strategy_ManageOpenPosition`
(lines 127, 133). Any tick where `Strategy_NoTradeFilter()` returns true
(insufficient warmup, missing quotes, or spread > 0.25*ATR; lines 56-66) therefore
suppresses exit management on an already-open position. An exit path must never sit
behind an entry-eligibility return.
Fix: move `Strategy_ManageOpenPosition()` (and any exit work) ahead of every
no-trade/entry-eligibility return.

### D2 (Medium) — invented spread filter is not in the approved card
`strategy_spread_max_atr = 0.25` (line 47) and the whole `Strategy_NoTradeFilter`
spread gate (lines 54-69) are not part of the card. The card's only filters are:
skip incomplete daily bar, one position per magic, and an *optional* P3 fresh-down-bar
rule (`low[0] < low[1]`). The spread filter is the mechanism causing D1.
Fix: remove the invented filter (or obtain an explicit card amendment), which also
resolves D1.

### D3 (Medium) — cohort exceeds the card's authorized universe on 3 symbols
Card authorizes SP500.DWX (backtest), NDX.DWX/WS30.DWX (live caveat), and
"optionally FX majors for breadth" (card Mechanik/R3). The FX majors in the package
(EUR/GBP/USD/JPY/CHF/AUD/CAD/NZD) are therefore card-permitted. But the package also
registers and emits setfiles for **GDAXI.DWX, UK100.DWX and XAUUSD.DWX**, none named
in the card; XAUUSD is not even an index. Prior review over-counted (it flagged FX too);
the actionable overreach is these 3 symbols.
Fix: drop GDAXI/UK100/XAUUSD or obtain an OWNER `target_symbols` amendment.
