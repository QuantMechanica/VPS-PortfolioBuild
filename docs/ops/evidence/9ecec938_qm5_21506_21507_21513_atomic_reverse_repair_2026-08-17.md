## Outcome

All three scoped EAs now use the same fail-closed reversal sequence:

1. Manage an existing position on every tick.
2. Return unless this is a new bar.
3. Advance the strategy state for the new bar.
4. Manage the existing position again against that fresh state, allowing the old-direction position to close before entry evaluation.
5. Apply the news gate.
6. Reject entry while *any* owned position remains, regardless of direction.

This is a two-hunk semantic repair in each EA: add `Strategy_HasOwnedPosition()` and use it in `Strategy_EntrySignal()`, then add the fresh-state `Strategy_ManageOpenPosition()` call in `OnTick()`. The strategies retain their own state calculation and exit rules; only the predecessor/reversal lifecycle shape is shared.
