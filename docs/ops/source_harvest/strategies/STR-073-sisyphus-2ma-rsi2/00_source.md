DISCLAIMER: THIS IS NO GRAIL. I AM NOT CLAIMING THIS TO BE A HOLY GRAIL. THIS IS
JUST A SYSTEM THAT WORKS, THAT IS ALL.
Things To Keep in Mind:
1. This is intended to be traded on Daily Charts. I will also post the results for other
timeframes towards the bottom of the post(coming soon).
2. There is no Hard SL or TP to this system. I have not found any configurations using ATR
or similar tools to place an SL & TP that improved the system. As a result I do not use one
with this system and just following the signals.
3. This system is not perfect. As with all systems, it performs better on certain pairs
during certain conditions. What really allows you to take advantage of the system and
avoid this variance is diversifying the instruments you trade it on!!!
4. Test results used a fixed lot size that does not increase.
5. Tests were performed on 7 major USD pairs(EU, GU, AU, NU, UJ, UCHF, UCAD).

Entry Rules:
Long:
1. Price is above 200 MA.
2. Price is below 5 MA.
3. RSI(2) is below 5.
Short:
1. Price is below 200 MA.
2. Price is above 5 MA.
3. RSI(2) is above 95.
