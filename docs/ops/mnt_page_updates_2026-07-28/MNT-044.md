# MNT-044 — Q06/Q07-Altlast re-adjudizieren

> **Status:** OFFEN · **Priorität:** P0 (live/promoted/Admission-konsumierte Offender) / P1 (historischer Rest) · **Befund + Lösungsidee:** von **Claude** (Review-Audit 2026-07-28) · **Konvergiert mit Codex-Position Runde 3 (2026-07-29, 95 %)** · Keine rückwirkende Gate-Freigabe, keine Live-Änderung.

## Problem

MNT-017/018 sichern künftige Läufe; die **Altlast bleibt gestempelt**: Q07-PASS-Zeilen mit Seed-Varianz 0,00, ein großer Anteil PASS-Zeilen ohne existente/lesbare Evidenzdatei (Snapshot 28.07. 23:40Z: 244 PASS, davon 106 ohne Datei, 23 lesbare Aggregates mit Varianz 0,00), **13128/NDX live mit Q07-„PASS" = parse_error-Backfill-Stempel ohne jeden Lauf** (work_item 37308752, `attempt_count=0`). Root Cause EA-seitig (fehlende Seed-/Stress-Inputs; Baskets via QM_BasketOrder-Bypass). Der aktuelle Q07-Runner authentifiziert neue Läufe bereits fail-closed (`q07_multiseed.py:173-210,540-613`) — die Lösung re-adjudiziert den Altbestand über diesen Pfad, sie baut keine zweite Seed-Auth.

**Codex-Dissense, übernommen:** (a) Rohzeilen werden **nie** umgeschrieben — `PROVENANCE_UNVERIFIED` lebt in einem append-only **Adjudication-Overlay** (`work_item_id`, Original-Verdict, effektiver Admission-Status, Grundklasse, Reviewer, Zeitstempel, Evidence-Hash); Pipeline-/Dashboard-Leser konsumieren den effektiven Status. (b) Das Offender-Register wird **bei Bill-Erstellung frisch erzeugt**, nie aus festcodierten Beispielen — 1567/EURUSD ist inzwischen INFRA_FAIL mit echtem Lauf, 1567/XAUUSD neu PASS; nur 13128/NDX ist unverändert klar P0. (c) „Aggregate existiert" reicht nicht: parsebar + rückverweisend auf fünf requested/effective-Seed-Paare, Summary-/Report-Hashes, EX5, MQ5/Closure, Setfile, Symbol, Zeitraum.

## Lösungsvorschlag

1. **Reproduzierbarer Offender-Scanner** mit Klassen `MISSING_FILE`, `UNREADABLE`, `NULL_KPI`, `ZERO_VARIANCE`, `PARSE_ERROR_BACKFILL`, `SEED_AUTH_MISSING`, `IDENTITY_HASH_MISSING`, `BINARY_VINTAGE_MISMATCH`; arbeitet über Invarianten, setzt keine Gesamtzahl voraus.
2. Scanner schreibt das **append-only Adjudication-Register**; keine `work_items`-Rohzeile wird verändert.
3. Live/promoted Offender werden **fail-closed** aus Promotion, Ranking und Portfolioentscheidung ausgeschlossen, bis neue identitäts- und seed-gebundene Q07-Evidenz oder eine OWNER-Entscheidung vorliegt — `PROVENANCE_UNVERIFIED` ist nie „PASS bis Entscheidung".
4. **Vor Rerun:** statische Verdrahtungsprüfung (Seed-/Stress-Inputs erreichen den ausgeführten Entry-/Orderpfad; Basket-Pfad separat) plus MNT-043-Binary-Bindung. Rerun exakt pro `(EA, Symbol, Setfile, Binary-SHA, Zeitraum)`.
5. `parse_error`, Backfill, fehlende Datei oder fehlende Seed-Achse können strukturell keinen effektiven PASS erzeugen (Regressionstest).
6. Ergebnisse je Live-Sleeve als OWNER-Vorlage (halten / verschärfen / entfernen) — keine automatische Live-Änderung.

## Akzeptanzkriterien

- Kein effektiver Q07-PASS ohne lesbares, hash- und seed-authentifiziertes Aggregate.
- Jede Overlay-Zeile ist auf unveränderte Rohzeile + Evidenzhash rückführbar; keine Admission-/Cascade-Abfrage konsumiert `PROVENANCE_UNVERIFIED`.
- 13128/NDX besitzt einen echten Lauf oder eine explizite OWNER-Entscheidung.

Evidenz over Claims gilt rückwirkend; Rohzeilen bleiben append-only erhalten. Abhängigkeit: MNT-043 (Rebuild vor beweisfähigem Rerun).
