With the default biased central-moment estimators and Fisher excess kurtosis,
the implementation fixes:

```text
mean = sum(x[i])/n
m2 = sum((x[i]-mean)^2)/n
m3 = sum((x[i]-mean)^3)/n
m4 = sum((x[i]-mean)^4)/n
skew = m3/(m2^1.5)
excess = m4/(m2^2)-3
JB = n/6 * (skew^2 + excess^2/4)
```

## Exact Mechanic

On the first executable `XTIUSD.DWX` D1 tick after a genuine broker-month
transition, reconstruct exactly forty-nine consecutive completed broker-
month-end closes `C[0]..C[48]`, oldest to newest. Exclude current-month prices
and form forty-eight chronological adjacent log returns:

```text
x[i] = ln(C[i+1]/C[i]), i=0..47
mean = sum(x[i])/48
d[i] = x[i]-mean
m2 = sum(d[i]^2)/48
m3 = sum(d[i]^3)/48
m4 = sum(d[i]^4)/48
skew = m3/(m2^1.5)
excess = m4/(m2^2)-3
JB = 48/6 * (skew^2 + excess^2/4)
mom12 = sum(x[i], i=36..47)

BUY  iff JB >= 1.04 and mom12 > +1e-12
SELL iff JB >= 1.04 and mom12 < -1e-12
FLAT otherwise
```

Require positive finite closes; finite returns, mean, centered values,
moments, standardized moments, statistic, and momentum; and `m2>1e-18`.
The squared skewness and excess-kurtosis terms deliberately make the gate
directionless. Only the independently sourced newest twelve-month return
supplies trade direction. A nonqualifying gate, neutral direction, or invalid
state consumes the month flat. Neither statistic nor momentum magnitude
changes risk.

The inclusive `1.04` boundary is the two-decimal pre-data approximation to
the median `1.0396466455041877` from 200,000 independent 48-observation
standard-normal paths generated by NumPy PCG64 seed `20260902`. It is an
empirical finite-sample cadence divider, not a normality-test critical value,
p-value, market calibration, or profitability claim. The receipt is
`artifacts/qm5_wti_mjb_tr_null_density_20260902.json`.
